# Pass plans (executed)

Tickets for passes already run against a product on [the clock shelf](../README.md). **Each is a record of one pass, not a live instruction** — every one is headed `EXECUTED`. Kept because a product's provenance is part of reading it.

**Where a new pass plan goes:** here, next to its siblings, and **the product it serves links it when the pass is executed**. A pass plan nobody links is provenance nobody can find.
