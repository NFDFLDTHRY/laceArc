## 3. Q2 — Where do definition words' own definitions participate?

**Answer: as further routes through the same ordinary word-stars when that further definition text is fed.** Piece 9 does not give definition words a different type. The live law's **MEANING in this project** block explicitly says that a word is defined by words and those words are defined by words; definition is a route through stars, and recursion is Continue, not a closed splice. [Sources: Piece 9][m7to11], [live law][law], [reason map RM8–RM10][reason].

Combining those statements supports recurrent definition-route participation in the same growing structure. It does **not** say that seeing one word automatically retrieves a dictionary entry, recursively expands all reachable definitions, computes a closure, or emits a particular set of POINTER rows. The missing premise for any such stronger claim would be an actual operation specifying that behavior. Neither a shared word nor an infinite-wire description supplies that operation by itself.

The consequence is not that definitions are absent because meaning is not stored. It is that the project represents the described relationship as retained routes and participation rather than a meaning field. No glossary is attached to a WORD row.

**Diagram location/disposition:** the companion names dictionary wiring and warns against a stored definition, but the positive recursive relationship is not explained there. The law supplies it. The minimum missing presentation is the explicit link from ordinary definition words to their further definition routes, qualified as the source account rather than an automatic expansion algorithm.
