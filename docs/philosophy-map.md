# Philosophy map: three texts beside the shoe

Source of record remains `docs/graphics/` and `docs/systems-manifest.md`.
Physical test remains `docs/reason-model-map.md`.
This file only says how three *philosophical* texts sit on that object.

They are not a sixth graphic. They are not WORD. They are not POINTER.
They describe how a *mind* and a *talk* compile. Lace stores neither mind nor talk-as-meaning.

Marks: **kin** / **adjacent** / **conflict** / **off-shoe** / **[GAP]** / **[CONFLICT]** as in the reason-model map.

The human labeled these “primary philosophical source material.” Primary for *steward seeing*. Not primary for Core storage.

---

## The object they must survive

On a shoe you may add cord and pass it again. You may not merge two wraps into one, re-index a wrap to a tidier hole, or delete a wrap because the story improved.

HCC-A’s Story Ledger names addition, merging, re-indexing, and deletion as native operations. That ledger, applied to Graphic D, is Rule Zero dying.

## 1. HCC-A v1.0 — Human Cognitive Compiler Architecture

Kind in source: self-mapping / other-mapping / interaction forensics spec.
Loop: Reality → Interface → RIC∥PFC → Compiler → Story Ledger → Meaning → Emotion → Identity → Behavior → Reality.

### Author pieces

**H1 — Reality (R)**  
Objective, constraint-bearing, “not directly accessible by any mind.”  
Hands: **adjacent** to “the cup hits the floor.” Not a Lace store. Lace does not model inaccessible R; it appends arrivals.

**H2 — Interface (I)**  
Body converts R → raw signals.  
Hands: **off-shoe** for Core. Steward-adjacent as “how a holder senses.”

**H3 — RIC (Raw Input Channel)**  
Preserve external structure: “X said Y”, timing, sequence, cause/effect traces. Runs **in parallel** with PFC.  
Hands: **kin** of Piece 3 punch-card and RM3. Structure kept. Order kept.  
Stops being kin if RIC is stored as a second log beside the array.

**H4 — PFC (Pre-Filter Channel)**  
Same signals through priors, templates, roles, threat models, ideology. Assigns interpretations *before* full compilation.  
Hands: **conflict** if PFC becomes ingest. That is Xiao intern + meaning table before append.  
**adjacent** as a diagnosis of why a steward misreads Graphic D.

**H5 — Compiler (C)**  
“Mechanism that converts structure → story.” Updates the Story Ledger.  
Hands: **conflict** as Core operator. Lace forbids structure→stored-story. Piece 14: no stored meaning.

**H6 — Story Ledger (L)**  
Internal event log. Supports **addition, merging, re-indexing, deletion/suppression**. “Ledger is not narrative form.”  
Hands: **[CONFLICT]** with Piece 1 and Piece 6. Merge / re-index / delete are Reidemeister-shaped writes plus Xiao mask.  
Addition-only would have been kin. The spec does not stop at addition.

**H7 — Meaning Engine (M)**  
Weights + transitions on the ledger. “Meaning is directive.” It “influences what happens next.” Modes: descriptive / evaluative / directive.  
Hands: **[CONFLICT]** with Piece 14. Directive meaning is a stored gloss that writes behavior. Lace: routes, touches, participation — not weights.

**H8 — Emotion Engine (E)**  
“Meaning-in-flight.” Not transmissible. Others generate their own E from their M+L.  
Hands: **off-shoe** for Core. **kin of a negation**: “Only structure is [transmissible]” matches “no meaning transfer” in the coffee-cup / water stack. Do not store E as rows.

**H9 — Identity Shaping Layer (ISL)**  
Compression into “what kind of agent am I.”  
Hands: **off-shoe**. Identity snapshot is not a star. A star is wraps through a word, not a self.

**H10 — Behavior (B) + Feedback**  
Only directly observable part of the loop. Behavior alters Reality; loop restarts.  
Hands: **adjacent** to AgentScope’s action dimension (the holder’s output). Not POINTER.

**H11 — Six-act stack / YAML person_model**  
Scene, story update, meaning, identity, behavior, world-rule. Per-person parameter sheet.  
Hands: **adjacent** steward forensics. **conflict** if YAML becomes a second store that owns WORD identity.

### Interface coherence (HCC-A → Core)

H3’s output (structured arrival) is the only output that matches Piece 3’s input.  
H6’s operations do **not** match Piece 6’s input (append-only section). The entity that would have to flow — “revised ledger” — is a rewrite.  
H7’s output (weights / must-do) does not match Piece 2’s output (more strand).

## 2. The Coffee Cup — how you actually see

Kind in source: five-stage walk-through. Empty cup so stakes cannot hijack structure.

### Author pieces

**C1 — Conditions before release**  
Elevation, gravity, distance, hand instead of table. “None of this causes the fall. It makes the fall possible.” Social analog: shared history, power, fatigue, unclosed pattern.  
Hands: **kin** of seeing the lace *before* the next pass — eyelets already there, cord already through some of them.  
Not a write. A read of what already exists.

**C2 — Release**  
Hand opens. Possibility collapses into motion. “Initiating, not decisive.”  
Hands: **weak kin** of an arriving word (Piece 2 “Input word arrives”). Arrival starts a pass. It does not decide the star.  
**conflict** if release is treated as permission to cut or to declare fate.

**C3 — Trajectory (control window)**  
Falling, not yet impact. Early intervention cheap; later expensive; then none. “Not a courtroom. A visibility discipline.”  
Hands: **adjacent** steward time. On a shoe this is *while you can still add a wrap that participates*. It is not Reidemeister (you do not pull a wrap out to “intervene”).  
Intervention on a lace is more cord, not less.

**C4 — Impact**  
Cup hits. “What did reality produce.” Ground truth.  
Hands: **kin** of Graphic D as the thing that actually happened (the array), vs the chart. Check the floor, not the story of the floor.

**C5 — Aftermath**  
Physics finished; causality not. Stories form; “Narratives alter future release thresholds.” Loop: conditions → release → trajectory → impact → narrative → rewritten conditions.  
Hands: **conflict** if aftermath *rewrites* prior WORD/POINTER rows.  
**adjacent** if aftermath is *new* appends (later participation) that leave the old wraps. That is hitch physics, not ledger delete.

**C6 — Planning as holding five stages at once**  
Not prediction. Literacy.  
Hands: **adjacent** steward posture. Not a Core operator.

### Interface coherence (Cup → Core)

C4’s output (what reality produced) matches a *read* of Piece 6.  
C5’s “rewrite conditions” matches Piece 11 only if implemented as later POINTER/WORD, never as edit-in-place. The source does not make that distinction. Lace must.

## 3. Where the Water Is Loud + Dual Proofing Systems

Kind in source: story + two proofing systems + interface FSM. Question: “Why are we talking so much and understanding so little?”

### Author pieces

**W1 — Story (food / “narrative” / exit / writing)**  
Pressure entered before orientation. One word read as a power move because no shared reference. Repair: “pick one thing you can point at.”  
Hands: **adjacent** steward tale. Not Core.

**W2 — Proof Ledger System A**  
OBS (pointable), DELTA (mismatch of OBS), UNK (missing, blocks comprehension), INVALID (no usable payload: “you’re bad”, “obviously”).  
Hands:
- OBS **looks like** POINTER. It is not. OBS is a conversational address (“the sentence you said”). Graphic D POINTER is a later *section of the same lace* naming earlier indices.
- **[CONFLICT]** if OBS nodes are stored as a graph beside the array.
- **kin** of the physical test: “If it can’t be pointed at, it is not OBS” ≈ “if you cannot do it to a shoe lace, you may not do it.”
- INVALID **adjacent** to AgentScope Action Mismatch / Wrong Context (heat, no compute).
- UNK **adjacent** to Lace `[GAP]`. Unresolved UNK in *talk* blocks crossing. Unresolved `[GAP]` in Core blocks implementation. Same discipline, different object.
- DELTA **not** a Lace relation. Two OBS inventories pairing is talk-repair, not pointer-to-pointer.

**W3 — River System B**  
Banks, rapids (loud ≠ transfer), delta (crossing possible). Invariants: pressure ≠ transfer; crossing requires delta conditions; talks often start in rapids.  
Hands: **adjacent** location-sense for stewards and humans. **off-shoe** as storage topology. Graphic C’s dimensions are participation axes of one cord, not river regions.

**W4 — Interface FSM S0–S4 + functions Locate/Anchor/Pair/Unknowns/Reject**  
Shared states: Banks → Rapids → Delta setup → Crossing compute → Bank rebuild.  
Hands: **adjacent** over AGENTS.md conversations. **conflict** if the FSM is implemented as extra array types.

**W5 — Kernel sentence**  
“We’re in the rapids. Let’s pick one thing we can point at so we can reach the delta.”  
Hands: **adjacent** repair utterance. Allowed in steward chat. Not a WORD emission rule.

**W6 — Named open parameters in the spec**  
Pointer format for OBS; INVALID stop-word list; UNK halt vs budget.  
Hands: those `[GAP]`s are *theirs*, for talk. They do not close Lace pointer-emission. Do not fill Lace `[GAP]` from W6.

### Interface coherence (Water → Core)

W2 OBS output does not match Piece 5 input.  
Piece 5 consumes earlier *indices on the same line*. OBS consumes a quote/time/message-id in a conversation. Fusing them would invent pointer-emission from a talk protocol. Forbidden.
