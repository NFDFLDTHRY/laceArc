## 2. Method

For every mechanism the three sources name:

1. **Cite it** — file and line in `refs/local/`, not the clipboard's compression.
2. **Classify it** into one of four:

| Class | Means |
|---|---|
| **admission** | decides whether a thing may enter at all (`I-A1` pointability) |
| **derivation** | decides operands or structure from what is present (`H1` root touch) |
| **retention** | decides whether discovered structure is **kept** — *the gate's actual `[GAP]`* |
| **not stateable** | cannot be expressed as a bench candidate. **Record why. This is data** |

3. **Implement** every `admission` and `derivation` candidate against [the bench](tools/lace-candidate-run.py), with its provenance declared.
4. **Run**, and publish the table whatever it says.

**Provenance is printed and not weighed.** A mechanism from a staked source earns nothing here that an editor's guess does not. That is pass 1's rule, already enforced in the instrument.
