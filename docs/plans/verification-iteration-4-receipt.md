### How to re-derive each, exactly

```
tracked / markdown   git ls-files | wc -l        git ls-files '*.md' | wc -l
ownership            docs/coord/coord.sh which <path>, for every tracked path;
                     empty output is unowned
advisories           .claude/hooks/check-docs.sh — the summary line now
                     breaks the count into its four classes
```

**Reachability** is a breadth-first walk of markdown links, and the method is the part a later reader must not have to guess:

- **Entrances:** `docs/README.md` and the repository root `README.md`. Adding `AGENTS.md`, `CLAUDE.md`, the live law, the manifest or the staking document changes the figure by **zero** — measured in [pass 1 §1a](verification-iteration-4-plan.md).
- **Edges:** `](target)` in **prose only** — fenced blocks and inline backticked spans blanked first, the way `_prose` in the hook does it. A path inside a fence is a mention.
- **Resolution:** relative to the containing file, normalised, `#fragments` dropped, `http:`/`mailto:`/`tel:` skipped.
- **Count:** tracked `*.md` files not reached.

**No script is committed for this.** Adding one would be adding code, and [the standing order](../../CLAUDE.md) says ask — which this campaign did once, for three named items, and does not treat as a general licence.

### What a later reader should check

**If the 39 has grown and no campaign was convened, the habit is weaker than pass 4 measured. If it has held, it is stronger.** That is the whole test, and it is now one walk away instead of an argument.

## 8. Should there be an iteration 5?

**No — not as a measuring campaign.**

Four iterations have now each ended by finding the **measuring instrument** wrong rather than the tree: iteration 1 found the range checker wrong, 2 found four checks failing their own labels, 3 found eleven queued repairs that were all correct as written, and **4 found its own thesis wrong in three of its four working passes.** §3 is seventeen entries long, ten of them this iteration correcting itself — and **the seventeenth is the one the campaign could not catch**, which is the sharper reason to stop measuring and start ruling.

**That is a campaign that has run out of things to be wrong about, which is the good outcome and also the signal to stop.**

**What is left is not measurable.** Six human rulings, one structural question about the station model, and a decay baseline whose whole purpose is that **nobody has to convene anything to read it.**

**If something does open, it is not a verification iteration.** The one named, unowned question this iteration produced is **§7's row five**: a campaign whose output lands on shelves it does not own has no door, and the station model has no answer. That is a **coord** question and it belongs to whoever holds that protocol — not to another six passes of measurement.

**Recommendation: close the campaign. Leave the baseline. Let the next thing be a ruling or a repair, not a survey.**
