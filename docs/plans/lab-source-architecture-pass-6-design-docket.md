# LAB SOURCE ARCHITECTURE — Pass 6 design-decision docket

**Status:** prepared by Pass 6 after cross-family synthesis. **NO RULING TAKEN.**  
**Authority:** **NOT CANONICAL ARCHITECTURE.** This docket does not change SM-GAP-RM, the manifest, pointer-emission, or Core law.  
**Purpose:** state the remaining design/ruling obligation narrowly enough that a future human decision does not have to rediscover the evidence boundary.

## 1. What is already fixed

The following are not part of the future design choice:

1. **Authoritative state:** one append-only Graphic-D Lace.
2. **Arrival:** every successful word arrival becomes its own WORD row.
3. **RootTouch:** seen occurrence → Join(new occurrence, root).
4. **POINTER constructor:** binary Join over earlier same-line WORD/POINTER points.
5. **Finite grounding:** an already-selected ordered finite sample of addressable Lace points can be grounded by repeated Join.
6. **Sampling:** H7–H12 establish derived position×scale structural discovery, not a semantic chooser.
7. **Search:** reconstructible/disposable search handles and witness paths, no write authority.
8. **Persistence:** once recorded, participation remains and may participate later.
9. **RM-B partial closure:** a selected contiguous sample occurrence can be mapped to its existing constituent WORD rows and grounded by L-M19.
10. **RM-C class-specific closures:** RootTouch has (new occurrence, root); contiguous sample grounding preserves the sample's intrinsic source order.
11. **No source family supplies a lawful general RM-A retain predicate.**

## 2. The remaining primary obligation — MISSING-A

The future design/ruling must supply an authority-backed transition:

~~~text
INPUT
    sampling-derived structural evidence
    reconstructed from the current Lace prefix

OUTPUT
    decision that a specific discovered structure
    warrants durable retention as Lace
~~~

The decision must be precise enough that downstream machinery can identify the selected structure and invoke any applicable RM-B/RM-C machinery.

This is not a request for:
- another POINTER constructor;
- a semantic search engine;
- a graph database;
- a persistence rule after the write;
- a platform API;
- a source-family analogy.

It is the retain-when decision itself.

## 3. Required input discipline

A future rule may consume only inputs whose authority is explicit.

Possible legal classes already available:
- sampling cell / ridge / recurrence evidence from L-M20;
- reconstructible search/witness facts from L-M21;
- current root/star/retained topology facts from Lace;
- exact bounded specimen facts when explicitly frozen;
- an additional input introduced by a **new human ruling/design**, if the ruling names it and its authority.

It may not silently consume:
- meanings/similarity scores;
- embeddings;
- external learned-model state;
- future rows/outcomes;
- D1 answer labels;
- hidden document/provenance classes;
- source-domain quantities such as physical tension or ReAG semantics unless a new ruling explicitly creates a lawful correspondence.

## 4. Required output discipline

At minimum a future RM-A rule must identify:

~~~text
retain?          YES / NO
selected object  what discovered structure is being retained
evidence         which lawful prefix-derived facts justified the decision
~~~

If the selected object's identity already specifies addressable operands, current RM-B machinery may continue.

If not, the rule/design must additionally state enough structure for a lawful RM-B adapter to identify its finite constituent Lace points.

The future design does not need one universal RM-C rule if the selected candidate class already has intrinsic order.

## 5. Forbidden answer families already tested

The future ruling/design must not silently revive:

- every adjacent pair;
- every sampled cell;
- exact-repeat-only retention;
- first-seen-every-cell materialization;
- cheapest-contiguous universal grounding;
- semantic similarity / embedding threshold;
- “B8 says it remains, therefore retain it”;
- D1 lookup / caption grammar;
- chronological ref_A/ref_B convention;
- A5 occurrence count renamed HCC-A weight;
- Kauffman no-slip renamed retain;
- Rowlands nilpotency renamed retain;
- Xiao token selector renamed relation retention;
- AgentScope ReAG/neural evidence imported as Lace state;
- future/downstream-outcome selection;
- platform primitive as semantic policy.

## 6. Partial machinery available for reuse

A future design may reuse, without re-deciding:

### Discovery
- L-M20 multi-scale sampling;
- L-M21 reconstructible search/frontiers/witness paths.

### Addressability/materialization
- WORD row identities;
- POINTER rows;
- L-M19 repeated Join;
- Pass-6 contiguous-sample RM-B derivation.

### Ordering
- RootTouch order;
- intrinsic order of a selected contiguous sample;
- candidate-specific order when a future candidate's lawful structure defines it.

### Evidence discipline
- prefix-only execution;
- replay/reconstructibility;
- D1 oracle-independence classes;
- TP/FN/FP + pair/event mismatch accounting;
- Petersen-style non-identification warning: finite fit is not mechanism identity.

## 7. Questions a future ruling/design must answer

The smallest current question set is:

1. **What structural condition on lawful sampling/search evidence warrants retention?**
2. **What exact discovered object is selected when that condition fires?**
3. **If that object is not already a finite ordered set of addressable Lace points, what constituent-point description does the rule provide so RM-B can proceed?**
4. **What evidence would falsify the rule?**
5. **Does the rule apply universally, or only to a declared candidate class?**

A design that cannot answer question 2 is not an RM-A rule.

A design that answers question 1 with a scalar threshold must also name the authority for both the scalar and the threshold.

## 8. Evidence a future design must survive

At minimum:
- source/authority declaration;
- no forbidden side state;
- prefix legality;
- derived-state replay;
- oracle independence;
- false-positive accounting;
- D1 bounded test without oracle tuning;
- controls: RootTouch calibration, CheatingMemory, SidecarMemory;
- at least one out-of-D1 structural specimen before any general claim.

The last item follows from the now-repeated non-identification finding: D1 consistency alone cannot identify the rule.

## 9. What this docket does not do

This docket:
- does not propose a retain predicate;
- does not rank possible predicates;
- does not select a threshold;
- does not choose a semantic representation;
- does not accept pointer-emission;
- does not authorize Core code;
- does not close SM-GAP-RM.

It records why further blind source search is no longer the missing step.
