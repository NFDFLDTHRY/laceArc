## 0. Source-level thesis

The Coffee Cup is a mechanism for **causal literacy under time**.

Its target is not merely “recognize five labels.” It requires the observer/system to preserve several causal distinctions simultaneously:

- conditions make an outcome possible without causing it;
- release initiates motion but is not trajectory or impact;
- trajectory is the live and shrinking intervention window;
- impact is resolved ground truth;
- aftermath is causally active in future conditions;
- the full event recirculates;
- planning means holding all five stages at once while time remains;
- the exercise is descriptive/structural rather than moral or blame-driven.

The five-stage language is source-defined mechanism structure. A concrete implementation need not store literal C1–C5 objects.

## 2. Exact causal relations

The source's core mechanism can be represented without implying implementation objects:

```
CONDITIONS
  enable but do not cause
        |
        v
RELEASE
  initiates motion
        |
        v
TRAJECTORY
  live / shrinking intervention space
        |
        v
IMPACT
  actual resolved outcome
        |
        v
AFTERMATH
  causal interpretation / adaptation
        |
        v
NEXT CONDITIONS
```

### Required non-equivalences

```
conditions != cause
release    != trajectory
release    != impact
trajectory != courtroom
impact     != possible outcome
aftermath  != commentary
aftermath  != historical impact rewrite
```

These are source-defined behavioral mechanism constraints.

## 3. Intervention-window mechanism

Pass 4 preserves more than “opportunity shrinks.”

Source requirements:

1. intervention exists after release and before impact;
2. earlier intervention is easier;
3. later intervention requires more speed;
4. later still only partial mitigation remains;
5. eventually no intervention can change the event;
6. certainty is not a prerequisite for acting;
7. signals can be visible and still ignored;
8. social cost can suppress possible intervention;
9. the window is mechanical, not moral.

Pass-3 C-G2 captures points 1–5 but not 6–9.

**C-G2 verdict: PARTIAL-to-STRONG, not FULL.**

## 4. Strategic-literacy mechanism

The source's strategic theory is not reducible to event ordering.

Desired behavior:

```
hold five causal positions simultaneously
        |
        +--> see conditions without calling fate
        +--> recognize release without calling total cause
        +--> stay in trajectory without demanding certainty
        +--> check impact against Reality
        +--> anticipate aftermath changing the next start
```

This is a **model-of-causality behavior**.

A candidate that outputs correct stage timestamps but habitually:
- treats conditions as destiny;
- treats release as the whole cause;
- ignores the live intervention window;
- overwrites impact with narrative;
- ignores aftermath recurrence

does not satisfy this mechanism.

Pass 3 has no direct assay for C-BM09.

## 6. Immutable history / causal adaptation seam

Coffee Cup requires future conditions to change because of aftermath.

It does **not** require historical impact to be rewritten.

This fits naturally as an implementation obligation:

```
immutable past event / impact
        |
        v
later aftermath / interpretation / learned response
        |
        v
new conditions in a later round
```

Possible implementations remain open:
- derived holder state;
- new later entries;
- ephemeral policy state;
- other mechanism.

Pass 4 chooses none.
