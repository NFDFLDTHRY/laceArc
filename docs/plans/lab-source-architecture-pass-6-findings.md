## 4. Materialization is representability, not topology identification

L-M19 guarantees one legal addressable representative for a selected ordered finite sample.

It does not guarantee that a particular fold reproduces the unique relational topology shown by some existing witness with the same WORD coverage.

This matters for larger samples.

A left-fold grounding of the five WORD rows can represent the whole D1 word span, while D1 row 0010 reaches the same total WORD coverage through a nontrivial retained relation topology.

Therefore:

\`\`\`
same constituent coverage
        !=
same generating topology
\`\`\`

Petersen–Zech's finite-fit/non-identification warning applies directly to this distinction.

RM-B closure means **lawful materialization exists**, not **the historical relation structure has been uniquely recovered**.
