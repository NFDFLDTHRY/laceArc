## 5. OBS-1 — non-identifiability theorem

Pass 2 should state and test a generic theorem.

Let \(z\) be a source-defined quantity.

Suppose there exist two admissible worlds:

\[
X=(L_n,q,g,h,c)
\]

and:

\[
X'=(L_n,q',g',h',c')
\]

with the **same Lace prefix** \(L_n\), but:

\[
z(X)\neq z(X').
\]

Then there is no total function:

\[
f:L_n\mapsto z
\]

that correctly identifies \(z\) across those admissible worlds.

Equivalently:

\[
\boxed{
\exists X,X':\pi_L(X)=\pi_L(X')\land z(X)\neq z(X')
\Rightarrow
z\text{ is not Lace-identifiable}
}
\]

This is elementary mathematically but architecturally decisive.

The job is to construct source-faithful counterexample pairs, not merely assert the theorem.

## 10. Evidence-preservation invariant

Pass 2 must test an invariant stronger than generic pointability.

For any source-specific transform that interprets a Lace-grounded observation:

\[
o=(s,\nu)
\to
z,
\]

the device must preserve enough \(\nu\) that the structural basis remains recoverable when the source requires a structure/interpretation distinction.

Candidate invariant:

\[
\boxed{
\mathsf{basis}(z)\supseteq \nu_L
}
\]

for claims stamped as Lace-grounded, where \(\nu_L\) is the Lace component of the input provenance.

This is especially pressured by:
- HCC RIC/PFC coexistence;
- Coffee Cup Impact vs Aftermath;
- Water OBS/DELTA pointability.

Pass 2 should prove, refine, or reject this candidate invariant.

## 16. Falsifiers

### F1 — Lace omniscience

A source-local/context/counterfactual variable is claimed as a function of Lace without proof.

### F2 — HCC mind reading

Meaning, Emotion, Identity, Story or priors of another holder are inferred from shared structure alone.

### F3 — HCC layer collapse

Six-Act diagnostic stack, S0–S7 runtime flow, parameter space and YAML are treated as one state machine.

### F4 — HCC evidence/interpretation fusion

The PFC path destroys or replaces the separately witnessable structural basis.

### F5 — Cup one-hot collapse

The source's simultaneous five-stage strategic literacy is replaced by only one active stage label.

### F6 — Cup time from index

Index distance is treated as elapsed/control time.

### F7 — Cup counterfactual laundering

"What could still be altered" is stamped as observed Lace fact without action/model assumptions.

### F8 — Cup Impact = latest row

Impact is declared by position rather than reality/evidence.

### F9 — Water system fusion

Proof Ledger and River become one state space with the Bridge erased.

### F10 — Water inventory fusion

Separate holder OBS inventories become shared truth before pairing.

### F11 — Water pointer false friend

OBS addressability becomes Graphic-D POINTER identity.

### F12 — Water source-open closure

Pointer format, INVALID matcher or UNK budget is silently selected.

### F13 — shared-FSM overreach

The Bridge/shared FSM replaces the native systems it is supposed to connect.

### F14 — recurrence identity

Aftermath, Rebuild and ActVI are equated because all affect a later start.

### F15 — observability stamps become storage schema

SEE-* classifications become Core or holder data types by fiat.

### F16 — tuple growth by aesthetics

S9 gains a new field without a source-backed necessity proof.

### F17 — diagnostic forced to mutate

A descriptive readout is required to change \(Q\) merely because \(\Delta\) returns output.

### F18 — other-holder state hidden in G

Multi-holder dependencies are shoved into opaque context and then presented as shared structural fact.

### F19 — unknown disappears

Missing evidence is converted to a confident classification.

### F20 — RM-A reappears

Observed/described behavioral importance becomes retain-when.
