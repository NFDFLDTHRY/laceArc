## 6. Capability-vs-obligation quantifier audit

H5:

> the n+1 grounding construction is basically so any portion of lace can reference any other portion of lace be one point.

The source/ruling supports the capability form:

\[
\forall S\in\mathcal F(L),
\quad
\exists p:
Reach(p)\supseteq S.
\]

That means:

> for any selected finite addressable portion, the construction can produce one point representing it.

An automatic selector would require a stronger statement such as:

\[
\forall L,v,
\quad
\exists!\,S(L,v)
\]

and a rule establishing which \(S\) Core must choose.

Automatic materialization of all samples would require stronger still:

\[
\forall S\in\mathcal F(L),
\quad
\text{Core must emit }P(S).
\]

No H1–H6 sentence contains either stronger quantifier.

H6:

> there's on their own row of lace per sample size.

supports the n+1 construction scale once a sample exists. It does not identify the sample.

Therefore:

\[
\boxed{
\text{can ground any selected portion}
\not\Rightarrow
\text{must automatically choose a portion}.
}
\]

**F6-9 does not fire.**
