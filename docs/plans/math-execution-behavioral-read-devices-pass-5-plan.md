\]

- stop criterion;

\[
\boxed{
Detect\neq Resolve.
}
\]

A structured abstraction must declare which distinctions it preserves and which it drops.

### MC-8 — source kernel dominance

Generic machine operators may not invent:
- HCC state semantics;
- Cup causal objective;
- Water sharedness;
- source-open tolerances.

### MC-9 — local update fence

\[

may update device state.

### MC-10 — witness continuity
