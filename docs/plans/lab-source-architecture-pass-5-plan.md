## 3. Candidate admission gates

A research candidate must pass all five before harness execution:

```
G1 SOURCE FIDELITY
    preserve the source mechanism's original purpose

G2 INPUT AVAILABILITY
    every required input is legally available from the bounded Lace prefix,
    current derived sampling/search, or an explicit specimen freeze

G3 OUTPUT TYPE
    output genuinely matches RM-A, RM-B or RM-C rather than being renamed

G4 STATE / AUTHORITY
    no unreconstructible authoritative side state; no forbidden semantic store

G5 PREFIX LEGALITY
    no future/oracle/full-trajectory knowledge
```

Failure at a gate is a result. Do not repair the source with an editor adapter.
