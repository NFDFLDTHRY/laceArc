# 1. Source obligations preserved

The direct HCC-A source requires:

1. Reality \(R\) exists independently and constrains.
2. Interface \(I\) converts Reality into raw internal signals.
3. RIC and PFC receive the **same signals in parallel**.
4. RIC preserves external structure as faithfully as possible.
5. PFC applies priors/templates before full compilation.
6. Compiler combines RIC/PFC into a mutable Story Ledger.
7. Meaning operates on the local Ledger using priorities and produces weights/transitions.
8. Emotion is "meaning-in-flight", a runtime internal state.
9. Identity integrates Ledger + Meaning + recurring emotional patterns and feeds priors forward.
10. Behavior is the directly observable output.
11. Behavior changes Reality and the loop repeats.
12. Individual variation is parameter variation, not absence of components.
13. The Six-Act stack is a diagnostic/process view and must not be collapsed into the S0–S7 runtime sequence.
14. Only structure crosses between minds; Meaning/Emotion remain local.

These are **BEH-REQ**.
