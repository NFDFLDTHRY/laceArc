# 1. Kauffman — local decomposition, branch preservation, terminal evaluation, projection information

## 1.1 Physical object versus diagram/shadow

**Source loci:** Part I §2, printed pp. 8–14 / PDF pp. 27–33.

Kauffman deliberately moves from a physical rope/knot to a closed-loop topological abstraction, then to planar diagrams/shadows. The planar shadow by itself does not retain every over/under distinction; local crossing information supplements the shadow.

**Machine lesson — SRC-MECH / SRC-LIMIT**

A derived representation may be useful without being complete.

For a behavioral device:

\[
Representation(x)
\neq
x
\]

unless the representation declares which distinctions it preserves.

This independently supports Pass-4 PATH-1 / VIEW-1 and machine law MC-7.

It does **not** authorize a graph to replace Lace.

## 1.2 Bracket state expansion

**Source loci:** Part I §3, printed pp. 25–31 / PDF pp. 44–50.

At one crossing:
- form two local splicings, A and B;
- repeat across crossings;
- obtain complete states with no crossings;
- evaluate state contribution;
- sum the contributions.

The source explicitly gives both exhaustive and recursive forms.

Abstract machine shape:

\[
x
\longmapsto
\{x_A,x_B\}
\longmapsto
\text{descendant family}
\longmapsto
\text{terminal evaluation}
\longmapsto
\text{aggregate}.
\]

**Stamp:** **SRC-MECH** at the knot-polynomial scope.

### Useful project candidate

\[
\mathsf{Branch}
+
\mathsf{Terminal}
+
\mathsf{Aggregate}
\]

is a lawful machine-construction pattern for local device state.

### Scope fence

The branch family is not authoritative history.

\[
\text{Kauffman state tree}\neq L.
\]

The bracket/Jones invariant is not Lace meaning.

## 1.3 Ancestral reconstruction

The source notes that keeping the A/B split labels permits reconstructing an ancestral crossing from descendants.

**Machine lesson — SRC-MECH**

A branch transformation can remain audit/reconstruction capable if it carries enough local provenance.

This is a useful independent pressure for MC-10 witness continuity.

## 1.4 Skein-Template algorithm

**Source loci:** Part I, printed pp. 57–62 / PDF pp. 76–81.

The source provides an explicit branching algorithm:
- label a template/universe;
- walk the diagram;
- at a triggering crossing, generate switch/splice alternatives;
- decorate branches;
- continue recursively/iteratively;
- halt at decorated final nodes;
- evaluate/sum terminal contributions.

**Machine lesson — SRC-MECH**

Local triggering can drive structured branch expansion without making branches authoritative facts.

## 1.5 What does not generalize automatically

Kauffman's:
- knot equivalence;
- Reidemeister moves;
- A/B splice meaning;
- bracket weights;
- Jones normalization;
- closed-loop ontology

are source-domain machinery.

They are **not** generic behavioral semantics.

# 2. Rowlands — create/conserve, iteration, stopping, hierarchy; universality quarantined

## 2.1 Rewrite mechanism versus program realization

**Source locus:** Chapter 1 §1.5, printed pp. 18–20.

Rowlands explicitly distinguishes:
- the rewriting mechanism;
- a computer program used to realize/encapsulate it.

This is a useful architecture/source distinction.

\[
Mechanism
\neq
Implementation.
\]

**Stamp:** **SRC-MECH** for the distinction.

## 2.2 Recursion versus iteration

The source explicitly distinguishes:
- recursion: the relevant object/relation set is treated as already existing;
- iteration: objects/relations are successively built from the simplest state.

**Stamp:** **SRC-MECH** at the rewrite-system discussion scope.

This is useful for deciding whether a behavioral machine:
- reads a fixed candidate space recursively;
- or grows a device-local candidate frontier iteratively.

It does not alter Lace's append law.

## 2.3 Traditional stopping mechanisms

Rowlands' description of ordinary rewrite systems explicitly names stopping conditions such as:
- no change;
- cycling;
- specified iteration limit.

It also says different stopping mechanisms define different families of rewrite systems.

**Stamp:** **SRC-MECH** as a description of rewrite-system construction.

This strongly supports the project rule:

\[
\text{iterative device-local loop}
\Rightarrow
\text{explicit termination/control policy}.
\]

## 2.4 Create / conserve

The universal rewrite proposal uses two processes:

### create

Adds/delivers a new candidate symbol.

### conserve

Examines effects of the new symbol against existing symbols and identifies anomalies/inconsistencies.

A later source passage is especially sharp:

> conserve does not define the transition property; it identifies novel transition combinations that appear not to conserve the proposed totality.

The book also explains that unbounded recursive conserve would be impractical; it introduces a finite \(n\) and an iterative create/conserve construction.

**Stamp:** **SRC-MECH** for what Rowlands' proposed system says it does.

### Project-safe abstraction

\[
\mathsf{Generate}
\leftrightarrow
\mathsf{Check}
\]

is a candidate device-local pattern.

The particular "zero totality" condition is Rowlands-specific.

## 2.5 Source theory beyond the machine pattern

The book goes much further:
- zero totality as fundamental origin;
- NUCRS as universal machine order code;
- nilpotent Dirac structure;
- universal semantics/grammar;
- applications to biology/brains/language;
- foundational physics conclusions.

These are claims of Rowlands' theoretical programme.

For LaceArc Pass 5:

\[
\boxed{
\text{NUCRS universality claims}=[SRC\!-\!HYP]
}
\]

unless independently established by another authority.

The project does not adopt them as machine law.

- intermediate results;
- verification;
- determination of the next step;

# 4. Petersen–Zech — composition, parallelization, realization non-uniqueness, local residual update, robustness

## 4.1 Realization does not identify construction

**Source locus:** Chapter 2, Remark 2.2.

The source explicitly states that different:
- architectures;
- weights;
- biases

can realize the same function.

Thus:

\[
\boxed{
\text{same realized function}
\not\Rightarrow
\text{same internal construction}.
}
\]

**Stamp:** **SRC-MECH / SRC-LIMIT** of parameterized realization.

This is important for behavioral machines:

\[
BehavioralOutput
\not\Rightarrow
UniqueInternalState.
\]

It reinforces S10 non-identifiability rather than solving it.

## 4.2 Composition and parallelization

**Source locus:** Proposition 2.3.

The source constructs neural networks representing:
- scalar multiples;
- parallel tuple output;
- sums;
- function composition.

The useful machine abstraction is not that devices must be neural networks.

It is that mathematically typed functions may be composed and parallelized while preserving separate subcomputations.

**Stamp:** **SRC-MECH** for neural networks; project operator abstraction is **PROJECT-CAND**.

This is especially relevant to HCC's source-required RIC/PFC parallelism.

## 4.3 Residual blocks

**Source locus:** Chapter 17 §17.1, Definition 17.1.

Residual block:

\[
x\mapsto x+\Phi(x).
\]

The source describes it as learning an additive change relative to the identity path.

**Stamp:** **SRC-MECH**.

For LaceArc it may inspire an optional local-state update form:

\[
q'\!=q+\Phi(\cdots)
\]

only where \(Q\) actually carries a vector/additive structure and the behavioral source permits it.

It is not a generic state-update requirement.

It never applies to Lace.

## 4.4 Approximation / optimization / robustness limits

The book repeatedly separates:
- approximation capability;
- training/optimization;
- generalization;
- robustness.

It also discusses:
- non-convexity;
- missing best-approximation properties in some fixed network classes;
- adversarial examples.

**Stamp:** **SRC-LIMIT**.

Thus:

\[
\text{good approximation}
\not\Rightarrow
\text{behavioral truth/evidence}.
\]

# 5. Bi et al. / AGENTSCOPE — structured abstraction, invariant checks, candidate preservation, delayed attribution

## 5.1 ReAG / ISR structured representation

**Source loci:** §3.1–3.3.

AGENTSCOPE transforms raw trajectories into a Reasoning-Action Graph whose steps are enriched by ISR fields:
- Intent/Context;

**Stamp:** **SRC-MECH** for agent-diagnosis domain.

### Project lesson

A behavioral device may build a derived structured working representation if:
- its loss properties are explicit;
- it remains device-local/rebuildable or correctly provenance-stamped;
- it is not mistaken for Lace.

\[
ReAG\neq L.
\]

## 5.2 Neural invariants

The source defines failure-mode-specific invariant violations and uses LLM-guided neural functions for semantic checks.

**Stamp:** **SRC-MECH**.

The source itself distinguishes these from traditional symbolic invariants.

Thus:

\[
\boxed{
\text{neural invariant judgment}\neq\text{formal proof}.
}
\]

## 5.3 Candidate preservation before decisive judgment

AGENTSCOPE explicitly says candidate failures are:
- retained;
- kept with supporting evidence;
- not immediately reduced to one diagnosis.

A later decisive judgment chooses a root-cause candidate using the full trajectory.

**Stamp:** **SRC-MECH**.

This directly establishes:

\[
\boxed{
Detect\neq Resolve
}
\]

for the AGENTSCOPE design.

It is strong source pressure for MC-6.

## 5.4 Onset versus decisive error

The paper discusses trajectories where:
- earliest detectable issue;
- downstream manifestation;
- outcome-committing/decisive failure

can be different positions on one propagation chain.

Alternative selection objectives are acknowledged as future possibilities.

**Stamp:** **SRC-LIMIT / SRC-MECH**.

This is a major warning against premature single-candidate collapse.

## 5.5 Empirical limits

The reported system improves measured localization/attribution on the evaluated datasets, but remains far from perfect exact accuracy.

The paper also documents runtime overhead and notes some checks can run in parallel.

Therefore:
- structured decomposition has empirical support;
- it is not an oracle;
- the judge model remains fallible.

# 7. Source disagreement / non-unification

Important differences survive.

### Kauffman

Terminal states and aggregation are mathematically defined by knot-polynomial rules.

Behavioral machines do not inherit those weights/invariants.

### Rowlands

Create/conserve operates inside a proposed universal zero-totality theory.

LaceArc may borrow a generate/check pattern without accepting the theory.

### Xiao–Zhu

Candidate quality often depends on probabilistic models and task scoring.

Behavioral sources do not necessarily define such a score.

### Petersen–Zech

Composition results concern neural-network functions.

They prove possibility inside a neural function class, not that neural networks are the right behavioral substrate.

### AgentScope

The candidate set consists specifically of failure hypotheses over agent trajectories.

It does not define HCC interpretation, Coffee Cup causality, or Water shared reference.

Therefore:

\[
\boxed{
\text{five-source convergence}
\neq
\text{five-source common chassis}.
}
\]
