## 1. Verdict

**THE HUMAN'S LANGUAGE-AS-STRUCTURE HYPOTHESIS HAS DEEP EXISTING REPOSITORY SUPPORT. THE DICTIONARY-SEED IDEA ALSO HAS A DIRECT PREVIOUS HUMAN CHARGE AND A CLOSED SIX-PASS MAP. THE NEW WORK IS NOT "INVENT A SEMANTIC MEMORY." IT IS TO TYPE THE INTERACTION BOUNDARIES AND THE READER.**

The pass found:

1. **Recursive language structure is already project law.** Word definitions are routes through other word-stars; further definition text is ordinary Lace growth; no gloss/meaning table is permitted.
2. **Dictionary-as-seed is not new.** A 2026-09-20 six-pass campaign records the human charge that the dictionary is the Lace seed, wired first, with later text wired up to it.
3. That seed campaign deliberately kept three things separate:
   - seed ingest is ordinary Arrive;
   - definition-route / first-touch **shape** is known;
   - the firing/retention **when** remained open.
4. **No actual seed corpus is currently established.** Open #15 remains live. The older seed campaign found zero corpus bytes on main at its execution.
5. **Derived Star search already exists mathematically.** S3.6 supplies witnessed frontiers and disposable SearchHandles. Star search is explicitly read-only and not stored.
6. The current tree has **no single canonical "Star pattern" representation**, no generic structural similarity/ranking policy, and no generic Star→language decoder.
7. The phrase **"all input and output goes on Lace" is too coarse and conflicts with current law if read literally.**
8. Once decomposed, a narrower version survives:
   - admitted input → Lace is supported;
   - local candidate/device output → Lace is false;
   - rendered projection → Lace is false;
   - externally committed user-facing response → Lace is genuinely open;
   - feedback may produce later admitted input → Lace is supported.
9. **The architecture does not close RM-A.** It splits the problem into event admission/crossing versus structural participation/retention and exposes that RM-A may have been carrying policy-placement assumptions.
10. **The architecture does not select Mechanism A or B.** H2 remains the cheapest possible discriminator, but current traceability treats H2 as a historical grounding precursor/capability rather than a proven universal collapse obligation.
11. The smallest next question is therefore the **boundary/event algebra**, not a ranking algorithm and not a new RM-A ruling.

## 5. The strongest correction to the human wording

The human said, in effect:

> all input and output must arrive on Lace.

The current tree forces the following correction before that can be an executable claim:

```
"input"
    must split into
SUBMITTED_IN
ADMITTED_IN
REFUSED/PENDING_IN

"output"
    must split into
LOCAL_CANDIDATE
LOCAL_DEVICE_OUT
VIEW_OUT
EXTERNAL_COMMITTED_OUT
RETURNED_IN
```

Only:
- **ADMITTED_IN** is already a closed Lace append path;
- **RETURNED_IN** becomes Lace if later admitted;
- **EXTERNAL_COMMITTED_OUT → Lace** is the new open edge.

LOCAL output and VIEW output are currently fenced from direct write authority.

This is not pedantry. Without the split, the phrase "all output" would violate RD-1, S9.8 and Contract III.

```
dictionary / document / conversation text

           |
           | compare / generate / resolve locally
           v

           |
           | external crossing [OPEN]
           v
  committed response
           |
           | world/user reaction
           v
  future admitted input
           |

      same Lace history
```

That history can become a replayable evidence surface for:
- what input preceded what output;
- which structural evidence a device cited;
- which structural patterns recurred;
- what later input followed a response;
- whether a predicted structure matched a later observed structure.

It cannot, without further criteria, certify truth, causality, or optimality.
