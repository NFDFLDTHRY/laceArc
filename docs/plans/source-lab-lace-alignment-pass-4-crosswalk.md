## 4. Important tensions / non-equivalences

### 4.1 Cup action under uncertainty vs Water unresolved UNK

Coffee Cup says trajectory requires acting without certainty; options narrow even when intervention necessity is not certain.

Water says unresolved **required** unknowns block coherent comprehension.

These are not contradictory if the system distinguishes:

```
decision/action under bounded uncertainty
        !=
claiming coherent comprehension without required evidence
```

A future combined holder must not turn Water UNK into a universal “never act while uncertain” rule.

**Stamp:** PASS4-TENSION / compatibility requires scope distinction.

### 4.2 HCC mutable story state vs source-grounded structure

HCC explicitly permits story-ledger merge/re-index/delete/suppression and emotion-driven story rewrite.

HCC also assumes objective Reality and structure-only transfer.

Therefore the source itself requires a distinction between:
- holder-local mutable story/meaning;
- constraint-bearing external structure.

A future holder cannot make HCC ledger mutability equivalent to rewriting authoritative Lace history.

**Stamp:** SOURCE-WITHIN-DOC distinction + implementation obligation.

### 4.3 Water OBS “pointer-addressable” vs Lace POINTER

Water uses pointer/address language for a claim that can be located.

Lace POINTER is a specific retained Graphic-D relation row.

These are **not source-identical**.

**Stamp:** FALSE-FRIEND.

A Water OBS may eventually cite a Lace address, but that is a candidate implementation, not the source definition.

### 4.4 Cup “conditions” vs HCC PFC/templates

HCC priors/templates can contribute to Cup-like conditions.

Cup conditions also include gravity, support, distance, shared history, power, fatigue, boundaries, interfaces, etc.

Therefore:

```
HCC prior/template state ⊂ possible Cup condition field
```

is a plausible implementation reading, but:

```
Cup Conditions == PFC
```

is false.

### 4.5 River Delta vs Lace relation topology

Water Delta means crossable shared footing / paired observations.

Lace retained topology is not automatically a Water DELTA.

**Stamp:** FALSE-FRIEND / PASS4-HYPOTHESIS only if an interface later maps them.
