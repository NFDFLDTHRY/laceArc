# Lace shape — diagram-as-prompt for any agent joining the team

Layer III steward prompt. Not Hands. Not law. Not Core. Emission remains `[GAP]`. No `src/` from a prompt.

**What this is.** A paste-ready prompt whose body is a diagram. It does not tell the agent what its result must be. It tells the agent where every box came from, how strong each box is, which boxes are holes, and how to map anything it finds back onto the global systems manifest and its ASCII companion. An agent that silently fills a hole has failed the prompt; a source-supported finding must retain its evidence and acceptance scope.

Read [current context](context-pass.md), [pass 3 evidence](../plans/repo-update-pass-3-evidence.md), the published [pass 2 record](../plans/repo-update-pass-2-evidence.md), and the companion's named **Systems-level audit (pass 27)** / **Execution-model reading (pass 28)** sections and later scope notes. The reduction's 21-document door is a dated base; add the [rust-target Pass 1 mapping and Page G queue](../clipboards/rust-target-clipboard.md) for target work.

**Model scope:** no recorded candidate is established in-region; BLOCKED and REFUTED remain different. The execution model's M1 concerns strand-history observations, not pending-input or persistence state; I1/I6 apply within an OPEN-free interval. M3's intermediate frontiers require the additional S4.3 STEP-partition premise, not final D1 equality alone. The five SPOKEN custody locations are Q0/Q1/Q3/Q5/slot II. Read the governing records before reusing a stamp.

## Your task, whatever it is

1. **Pin.** State the commit you read. `git pull --ff-only origin main` first.
2. **Ground.** Open the four PNGs. Name the panel for every structural claim you make (D2, B8, C10 …). If you cannot see images, mark every image-dependent judgment `[BLOCKED]`.
3. **Map, do not define.** For every finding, give its address on the diagram above: which box, which manifest Piece, which companion slot (Spine / Contract map / Fence / Open board # / G-III-n / Leftover), which fence F-*, which ruling R-*. A finding with no address is not yet a finding.
4. **Stamp.** Origin, evidence state, human acceptance — on the sentence, not the document.
5. **If you find a candidate rule** (yours or anyone's), do not argue for it. Run all seven steps of [E7](../plans/lace-context-iter6-pass-4-environment.md#e7--the-procedure-what-an-agent-runs): write `σ(L, v)`, check the type and Hands fences, and **show every produced row beside D1’s eleven, treating missing or extra rows as mismatches**. A successful D1 run supplies the F-N witness; a missing witness is not proof of vacuity. Check F-G/F-B beyond D1 and require evidence for all thirteen predicates over their existing E2/E3 domains before unrestricted IN-REGION. Restricted-domain or D1-only evidence remains bounded; missing evidence stays UNESTABLISHED/BLOCKED as appropriate, distinct from a proved violation. Final D1 gaps do not establish per-STEP counts without the stated S4.3 premise. Return the verdict and named obligations; IN-REGION is still `[PROPOSAL]`, with acceptance ABSENT.
6. **If you find a hole,** write `[GAP]`, `[CONFLICT]`, or `[BLOCKED on …]` and the address. Do not close it with a schema, a default, a helpful example, or a "draft rule v0."
7. **If you find older-lineage vocabulary,** report it under QUARANTINE with its date and source. Do not translate it.
8. **Station.** `which → claim → edit only what you own → gate → commit → release`. One station per commit. Findings go into a maps-owned record, never into another campaign's file, never into `pointer-emission.md`.
9. **Return** the adjudication form ([template §3](../kit/agent-task-template.md)): claim and revision assessed · facts with evidence and scope · refutations with counterexamples · open obligations · files changed vs authorization · complete / needs work / blocked at a named boundary · one next narrow question.
10. **Say** whether propose / attack / resolve were one agent or separate. One agent is allowed and must be declared.
11. **When a commit is authorized, sign** it with an actor trailer and hold only the station your role names — [`docs/kit/roles.md`](../kit/roles.md). To start a campaign, use [the generator](six-pass-proposal-generator.md).

## What ends the task

Your artifact and its evidence exist; every box you touched keeps its stamp or gets a stronger one with a source; every hole you met is still a hole with an address; no `src/`, no Cargo, no type, no stub.

## Steward test

If you cannot do it to a shoe lace in your hands, you may not do it to laceArc.

A diagram of a hole is not a lid. Emission remains `[GAP]`.
