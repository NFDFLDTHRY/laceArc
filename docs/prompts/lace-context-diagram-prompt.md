## Your task, whatever it is

1. **Pin.** Pull/fetch the live branch and state the commit actually read.
2. **Ground.** Read `AGENTS.md`, then `context-pass.md`, then the sources/consumers of the assigned task. Open Graphics A–D for structural claims. If you cannot inspect them, mark image-dependent judgments `[BLOCKED]`.
3. **Classify.** State whether every claim is SOURCE, HUMAN, DERIVED, OVERLAY, LAB, PROPOSAL, HISTORICAL, or OPEN. Do not let a later file silently upgrade an earlier evidence class.
4. **Map.** Place findings on the current court above. S9–S12 are overlays above Lace, not new Graphic-D row types.
5. **Preserve the current gates.** RM-A, G1, R3, target selection, GAP-HOST, exact H×C×W coupling and acceptance remain open at their recorded scope.
6. **Refuse stale resurrection.** A sealed wasm64 instruction, A4-next instruction, old broad emission/arity gap, blocking-UNK target, lexical INVALID target, or “devices deferred” statement is historical unless a current governing source explicitly re-establishes it.
7. **Stations.** `coord.sh which <file>` → claim the owner → edit only owned paths → gate → commit → release. A prompt never grants cross-station authority.
8. **Return evidence.** Facts with citations/paths and scope; refutations; opens; files changed; what was not authorized; one next narrow question.

## What ends the task

The current state is reconstructed without inventing a missing rule, selecting a target, promoting a device into Core, or replaying a historical creation ticket.

A diagram of a hole is not a lid.
