Classification rule:

- **LIVE ENTRANCE** — intended to orient a fresh agent now; must tell the current story.
- **STANDING PROCESS** — reusable procedure against live tip; process does not itself authorize edits.
- **BOUNDED FUTURE** — reusable only when a new named task/probe/designated-editor scope explicitly reopens it.
- **HISTORICAL / COMPLETED** — preserves a creation/review task whose product already exists; do not replay its body over the product.

## Current prompt-shelf invariants

A LIVE or STANDING prompt must not:

- reseal `wasm64-unknown-unknown`;
- say Cargo A4 is still missing/next;
- present Passes 26–28 or Pass 38 as the current whole-repo tip;
- resurrect the old broad Φ/Q2 emission hole as current constructor law;
- omit S9–S12 while claiming to describe current machine mathematics;
- close RM-A, G1, R3, GAP-HOST, target choice or human acceptance;
- restore blocking-UNK or lexical-INVALID as current Water target law;
- turn the optional research operator library into a mandatory common chassis;
- equate Candidate with Evidence or Verifier with Truth;
- call a mathematical blueprint an implementation;
- create `src/`, Cargo, code, acceptance, or another station's authority.

A HISTORICAL prompt may contain older wording inside its preserved body **only when its current wrapper clearly says not to replay it**.
