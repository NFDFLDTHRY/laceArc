## 0. What pass 5 is, and the one way it goes wrong

**Pass 5 is the steward pass.** Pass 4 drew; pass 5 confirms the drawing still says what the tree says, and then writes down the order the shelf has been working to.

**The failure mode is a rubber stamp.** A CONFIRM pass that re-reads its own receipt and agrees with it has measured nothing. Every sibling shelf's pass 5 records *"CONFIRM · 19 PASS · 0 FIX"*, and a count that can only come out one way is not a count.

**So this pass may not quote pass 4's numbers. It re-runs them.** Four audits published yesterday — the emission word in fences, off-board tokens on refusal lines, fields and stamp lines, reach against the forge map — are executed again, from the file as it now stands, and the new numbers are what `P5-X` reports. If they differ, **pass 4 published a number it did not hold**, and that is `F4` below.

## 2. `P5-X`'s new check — cross-table consistency

Pass 4 wrote the same eighteen facts into **three** places: each panel's caption, the cross-walk row, and the `P4-X` row. **Nobody checked that the three agree.** Hand-written tables drift silently, and the reader has no way to know which one is right.

**The check.** For every `P-R<n>`: extract the spine nodes from the panel heading, and the stamp, reach and emission values from the panel's own field table; compare against that panel's cross-walk row and its `P4-X` row.

| Compared | Must agree |
|---|---|
| panel heading `· node …` | cross-walk *Spine nodes* |
| panel `Lace stamp` field | cross-walk *Hard stamp beyond the universal three* |
| panel `Reach` field | cross-walk *Reach*, **and** the forge's coverage map |
| panel `Emission` field | cross-walk *Emission* — all eighteen `[GAP]` |

**Any disagreement is `P5-F` work**, and the fix goes to whichever of the three the *panel's own evidence* supports — never to whichever is easiest to edit.

## 3. `P5-P` — what this shelf's order actually is

Every sibling shelf's Order Proposal says *observe → name → diagram-check → stamp-check → list OPENs → decide*. **That is not shelf 10's order, and copying it would be the fourth time this campaign nearly inherited a form it never earned.**

**Shelf 10 is the only shelf whose source is a text file that cannot be committed and that no other session can open.** The nine PDF shelves cite printed page numbers a human can look up; this one cites line numbers into a gitignored file. Every discipline this shelf invented came out of that one difference, and each was earned by a pass that got it wrong first:

| Stage | The rule | Earned by |
|---|---|---|
| **stake** | the source never enters git; it is named by SHA and held in `refs/local/` | pass 0 |
| **cut** | *an extract carries the lines a claim **rests on**, not the lines it **refuses*** | locator pass 2 |
| | *a fragment may be carried when its first line names the thing it defines* | locator pass 3 |
| | *a fidelity block records its own failures* | locator pass 1, after shipping 36 rows of `^M` |
| **gate** | every quote is re-read at **its own cited lines**, never against the source at large | the forge |
| **reach** | fail closed — a claim is checkable only when **every** range it cites is carried | the forge |
| **draw** | a decision or a duty, never a substance; and **reach and openness must not share a notation** | pass 4, `F3` and `R-D2` |
| **confirm** | re-run, never re-quote | this pass |

**That is the proposal**: an order for reading a staked source you are not allowed to commit. **Stamped `PROPOSAL` and `NON-binding`.** It does not amend `AGENTS.md`, does not touch the law station, does not bind the manifest, the graphics, or any of the nine sibling shelves — and it cannot, because only the human rules.
