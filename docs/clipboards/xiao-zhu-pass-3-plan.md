## What “system mechanism” means here

A **system mechanism** is a named procedure the book defines or runs in its LLM pipeline:

1. Named inputs / outputs / invariants  
2. A constructive algorithm (numbered steps a steward could follow on paper)  
3. A PDF locus  
4. A Lace stamp (KEEP-read / FORBID-as-Core-write / SILENT for Lace append / …)

Prefer the book’s own **pipeline / algorithms** (pre-train, tokenize, embed, next-token, MASK, soft prompt, SFT, RLHF, prefilling/decode/KV) over loose metaphors.

Not: Lace Φ, Graphic D writes, a Lace tokenizer, or a second store beside the strand.
