## ASCII drawing standard (rigor)

1. **Monospace only** inside fenced `text` blocks. No markdown tables inside the fence.  
2. **Book glyphs:** crossings as `X` / `><` / over-under with `=` / `-`; virtual as `(+)` or `o` on the cross (state once in a legend).  
3. **No Lace types in panel bodies** (`WORD`, `POINTER`, star-as-Lace). Stamps and false-friend lines live **outside** the fence.  
4. **Figure-authoritative:** if OCR cannot recover a figure, draw a **minimal** schematic and mark `figure-authoritative: PDF p.N`; do not invent crossings the book does not show.  
5. **Width:** prefer ≤ 76 columns so the panel survives chat paste (kin to law ASCII stake).  
6. **Reversible check:** a steward must be able to point from a panel label to an M-A algorithm step.

Kin style reference: law ASCII stake + `systems-manifest-ascii.md` box discipline — **imitation of discipline, not content**.
