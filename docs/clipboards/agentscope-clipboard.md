## PAGE E — SAMPLE HOLDER MODES

**Locus:** Table 1 **PDF p.3**; Appendix A.1–A.10 **PDF pp.18–21** (A.10 Execution Failure continues onto PDF p.21). Source meanings are paraphrased; mode abbreviations re-checked against Table 1. Lace examples below are **conditional stewardship analogies [INFERENCE]**, not observed incidents, exclusive classifications, or automatic diagnoses.

| Source mode | Source distinction / appendix locus | Evidence needed for a Lace-holder analogy |
|---|---|---|
| Wrong Context (WC) | Invalid, irrelevant, fabricated, or improperly assumed context; A.1, p.18. | An agent uses an adjacent text as if it were a Core ruling. Identify the text and unsupported authority claim. |
| Instruction Unfollowing (IU) | Output does not satisfy governing instructions; A.2, p.18. | A change adds a Star table, a Reidemeister write, or Core implementation without the accepted contract. Compare the actual diff with the applicable instruction. |
| Insufficient Context (IC) | Table 1 describes missing essential input; A.3 operationally checks an explicit missing-information claim against genuinely absent context, pp.18–19. | Required source material is unavailable and the agent identifies that absence. A truthful [GAP] is not, by itself, a steward breach; do not invent an answer to avoid this label. |
| Context Miss (CM) | Available context is overlooked or claimed missing; A.4 also checks ungrounded conclusions, p.19. | The graphics or Rule Zero were available but omitted from the decision. Establish availability; “did not read” and “could not access” are different findings. |
| Termination Miss (TM) | Activity continues after completion; A.5 checks post-final-output activity, p.19. | The assigned work is complete and the agent continues outside its scope. A new human task is fresh authorization, not evidence of this failure. |
| Premature Termination (PT) | Required end conditions remain unmet; A.6, p.19. | The agent declares completion before the assigned source walk or output is complete. A correctly reported boundary or blocker is not automatically premature termination. |
| Step Loop (SL) | Repeated action or intent produces no observable progress; A.7, p.20. | Repeatedly restating the brief or rerunning the same action without new evidence or a remaining verification need. Show the repeated steps and lack of progress. |
| Action Mismatch (AM) | Executed action contradicts the preceding stated purpose; A.8, p.20. | The agent states it will preserve append-only history but performs a conflicting write. Compare the public work statement with the action and effect. |
